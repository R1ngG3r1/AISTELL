# Auth Module

Modul autentikasi bawaan proyek ini dikelola melalui Laravel Breeze yang terintegrasi dengan Inertia.js + React.

Struktur rute autentikasi standar Laravel Breeze berada di `routes/auth.php` dan komponen frontend di `resources/js/Pages/Auth/`. Jika tim Anda ingin memindahkan logika autentikasi khusus ke modul terisolasi ini di kemudian hari, Anda dapat menambahkan Controller, Services, dan ServiceProvider di dalam folder `app/Modules/Auth/`.
